# Feature Specification

## Core Features
- Read EXIF/metadata from photo files (JPEG, PNG, HEIC, RAW)
- Display metadata in a sortable, filterable table
- Bulk edit metadata fields
- Export metadata to CSV or JSON

## GUI Requirements
- Main window with file browser panel
- Metadata detail panel
- Drag-and-drop file/folder import
- Dark mode toggle

## Out of Scope (v1)
- Cloud sync
- Face recognition
- AI tagging
